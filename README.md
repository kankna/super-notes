## 当前状态

第一版为 **GitHub Pages 纯静态站**：数据存在浏览器本地（IndexedDB），无需服务器即可使用。

已实现（里程碑 M0–M1）：

- 书架：可视化书盒、封面色与样式自定义、悬停详情、悬停时其余书盒缩小、拖拽排序、拖入回收站并可撤销、搜索、减少动效
- 项目概览：章节 / 学习单元 / 内容条目浏览，Markdown + LaTeX（KaTeX）渲染，答案默认收起可揭示
- 数据底座：Dexie / IndexedDB，档案间库级隔离，回收站墓碑

后续里程碑：项目画布 → 照片上传与 AI 整理校对 → 学习工作台与分步计时 → 疑点 AI 与检测题 → 模板与功能块 → 导出恢复 → AI 设置与真实调用。

## 本地运行

```bash
cd app
npm install
npm run dev
```

## 部署

推送 `main` 分支后由 `.github/workflows/deploy.yml` 自动构建并发布到 GitHub Pages。
